# Next.js File Detector 🚀

Automatically generates Next.js page components whenever a `page.tsx` or `page.jsx` file is created inside the `app` directory. No more typing `rafce` or `rsc` manually!

## Features ✨

* **Auto Detection:** Instantly detects when a new `page.tsx` or `page.jsx` is created under the `app/` folder.
* **Smart Naming:** Automatically names the component based on the folder name (e.g., `app/about/page.tsx` -> `AboutPage()`).
* **Auto Formatting:** Triggers VS Code's default formatter right after generating the code for clean spacing.

## How to Use 📖

1. Create a new folder inside the `app` directory of your Next.js project (e.g., `contact`).
2. Create a `page.tsx` or `page.jsx` file inside that folder.
3. The boilerplate code will be generated instantly and ready for use!
